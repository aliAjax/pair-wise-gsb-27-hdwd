# 物流报价与特价审批

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`
- 业务规则自测：`npm test`（67 条规则断言，无需浏览器）

数据默认保存在浏览器 localStorage（key：`hxwlfront-13-freight-v2`），右上角可切换**业务员 / 审批人**身份、恢复演示数据。

## 业务闭环

### 1. 按价表试算，金额逐项列明
- 价表按「线路 × 服务 × 重量阶梯」配置基础运费（起步价 + 元/kg），
  另含附加费（按重量或按基础价百分比，可限定服务）与常规合约折扣。
- 报价按**当前生效价表**匹配，逐项列出基础价、每笔附加费、每笔折扣、应收合计，
  并记录计价所用价表版本号（引擎见 `src/pricing.ts` 的 `calculate`）。

### 2. 客户确认后锁价，换版只影响未确认
- 报价三态：`待确认`、`待批`（特价审批中）、`已确认`。
- 客户确认后金额冻结；之后换版，已确认报价不变（旧版价表规则仍完整归档）。
- 未确认报价换版后被标记为**旧金额**（列表可筛选），显示与当前价表的差额，
  必须「按当前价表重算」后才能再确认或申请特价。

### 3. 特价申请 / 审批
- 业务员对未确认且已是当前版金额的报价提交特价：填申请金额（须低于常规价）和理由，
  原报价立即进入「待批」，同类在途申请只有一笔。
- 申请自带 **48 小时有效期**；逾期未批自动作废，报价退回待确认，需重算后再提交。
- 仅**审批人**可处理：驳回，或填批准金额批准；**批准额不得高于申请额**，
  亦不得高于常规价（界面与 store 双重校验）。
- 批准按申请时的价表版本叠加「特价审批折扣」，报价回待确认，客户确认后同样锁价。
- 批准后未确认又遇换版：仍按未确认处理——重算回当前常规价后可再次申请，旧批准记录留档。

### 4. 价表版本与全程留档
- 「价表管理」由审批人基于当前版改版（阶梯费率、附加费、折扣可编辑）后发布新版，
  历史版本只读归档。
- 创建/重算/锁价、特价提交/批准/驳回/过期、价表发布、删除等操作全部写入审计时间线，
  按「价表 / 报价 / 特价」分类查询，不随报价删除而清除。

## 目录

- `src/types.ts`：领域类型（价表版本、报价、特价申请、审计事件）
- `src/pricing.ts`：阶梯匹配与计价引擎（基础价/附加费/折扣/特价折扣）
- `src/store.ts`：Pinia store，全部业务规则与权限校验
- `src/seed.ts`：演示数据（v1/v2 两个价表版本，覆盖已锁价、旧金额、待批、已过期场景）
- `src/components/`：报价表单、报价卡片/列表、审批中心、价表管理、留档查询
- `scripts/selftest.cjs`：业务规则自测脚本
