# 物流报价与特价审批系统

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

数据保存在浏览器 localStorage 中（key：`hxwlfront-13-pricing-v1`），可随时清除存储恢复演示数据。

## 业务规则

### 价表（版本化）
- 按「线路 × 服务 × 重量段」配置基础价（首段按元/kg、其余按基础价＋续重元/kg）。
- 附加费：百分比（燃油）、按公斤（冷链温控）、按票固定（优先分拣、上门），可限定服务。
- 常规折扣：按客户类型自动匹配（协议客户 3%、大客户 8%）。
- 审批人发布新版本后旧版整体归档；已确认锁定报价金额不变，仅未确认报价受影响（提示新版金额，可单张或一键重算）。

### 报价
- 按线路、重量、服务匹配**当前生效价表**试算，基础价、附加费、折扣逐行列明。
- 「客户确认」后整单（含所用价表版本与特价减免）写入锁定快照，后续换版不影响。

### 特价申请与审批
- 业务员对未确认报价发起特价申请后，原报价进入「特价待批」，审批期间以申请时刻快照为准。
- 按折扣率分级、同类申请只能由对应审批人处理：
  - 一类（≤5%）：区经理
  - 二类（5%–10%）：销售总监
  - 三类（>10%）：总经理
- 批准折扣率**不得高于申请折扣率**（可降额改批）；驳回后原报价恢复常规报价。
- 申请有效期 3 天，到期未批自动作废，业务员须按当前价表重算后重新提交（旧申请留痕为「已重提」）。
- 批准后报价进入「特价待确认」，客户确认即锁定，也可放弃特价按常规价。

### 留档
- 价表：每个版本的全部规则随版本归档，可随时查看。
- 审批：每张申请保留提交、批准/驳回、作废、重提的完整审批经过。
- 操作审计：价表发布、报价新增/重算/锁定/删除、特价各节点均有审计日志。
